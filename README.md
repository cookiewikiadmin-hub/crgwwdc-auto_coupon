# WWDC Auto Coupon

บอทกดรับคูปอง DevPlay (CookieRun Classic) อัตโนมัติ

## ดาวน์โหลด

โหลดตัวล่าสุดได้ที่: **[AutoCoupon.exe](https://github.com/cookiewikiadmin-hub/crgwwdc-auto_coupon/releases/latest/download/AutoCoupon.exe)**

## วิธีใช้

1. ดับเบิลคลิก `AutoCoupon.exe`
2. ครั้งแรกจะดาวน์โหลดเบราว์เซอร์ที่จำเป็นให้เอง (~100MB, ครั้งเดียว — ต้องต่อเน็ต)
3. วาง DevPlay account (1 บรรทัด/1 ไอดี) + coupon code → กด **Start**

> โปรแกรมจะบังคับอัปเดตเป็นเวอร์ชันใหม่ล่าสุดโดยอัตโนมัติเมื่อเปิดใช้งาน

หมายเหตุ: ไฟล์ไม่ได้เซ็น code-signing certificate — Windows SmartScreen อาจเตือน "Windows protected your PC" กด **More info → Run anyway**
